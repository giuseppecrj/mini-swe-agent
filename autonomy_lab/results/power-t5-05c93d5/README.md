# T5 power simulation outputs

Produced by `autonomy_lab/power.py` at commit `05c93d5` (branch `lab/t5-analysis`) on 2026-10-17.

- `power.*`: the full grid.
- `confirm.*`: production-strength confirmation, 1,000 simulations × 10,000 bootstrap resamples.
- `e3ext.*`: E3 extension.

These are scenario-dependent simulations, not agent results. The assumptions are stated inside each file. Input to gate G2 (sample sizes, the P3/P4/P5 prospects, and E3 feasibility).
